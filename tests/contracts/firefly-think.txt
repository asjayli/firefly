@design 02
# firefly-think: facts to whoever can verify them, trade-offs to whoever
# carries the consequences; one question at a time, each answer with its
# acceptance condition; the minutes under openspec/think/ as the one record
# the spec later cites by pointer.

# Entry: named by the user, an open goal, or a decision handed over mid-flow.
+trigger: The user names `firefly think`
+trigger: still vague or evolving
+trigger: behaviors with different consequences
# Decidable skips: facts a system can answer, a decision already given.
+trigger: goes to `firefly-draw` as a single-question probe
+trigger: a third party's promise under the version and configuration in use goes to `firefly-source`
+trigger: The user has already given the decision

# Mandate: clarification is not implementation; no review of its own minutes.
+mandate: Think is for clarification, not implementation
+mandate: must not implement product code
+mandate: Dispatching any review of its own minutes
# Mandate: asking is this skill's own work; the endpoint is read off the mandate.
+mandate: Asking the user a question is this skill's own work, not an escalation
+mandate: a mandate that ends at clarification is not widened here
# Mandate: question discipline — one at a time, the most work-saving one,
# one acceptance condition per plausible answer, no re-asking.
+mandate: the one whose answer rules out the most wasted work
+mandate: one acceptance condition per plausible answer
+mandate: If two conditions do not differ materially, the question is unnecessary
+mandate: Do not re-ask anything the prompt, the project files, the memory or an earlier answer already settles
# Mandate: no deciding in the owner's place; memory stays read-only.
+mandate: Deciding a trade-off in the owner's place
+mandate: not agreement to anything the words did not explicitly delegate
+mandate: Read project memory read-only
+mandate: Do not write memory back

# Inputs: four accepted kinds, a named file is the record itself.
+input: a vague idea
+input: generated by `firefly diagram`
+input: a full requirement document
+input: is itself the requirement record

# Outputs: the minutes carrier, its four kept things, provenance carried forward.
+output: openspec/think/YYYY-MM-DD-<description>.md
+output: An earlier iteration of the same requirement is never overwritten
+output: the user's verbatim words, the selected behavior, the rejected interpretations
+output: cites these entries by pointer instead of reinterpreting
+output: Context Provenance
+output: the controller writes both
# The greenfield completeness matrix: only what is missing and design-affecting.
+output: only when an answer is missing AND it changes the design
+output: Target platform
+output: Data model

# Decision sources: three kinds, an inference keeps its mark until confirmed.
+verdict-or-state: `user-words`, `owner-confirmed` or `agent-inference`
+verdict-or-state: keeps its inference mark until the requirement owner confirms

# Handoffs: the probe, the dependency question, the proposal, the stop.
+handoff: under the version and configuration in use goes to `firefly-source`
+handoff: agreed behavior goes to `firefly-propose` with the minutes
+handoff: The controller dispatches what this skill recommends
+handoff: return the artifact and stop
# A missing decision maker: both consequences and a recommendation, no
# commitment; unanswered blocks that decision only.
+handoff: deliver both consequences and a recommendation
+handoff: Do not commit on their behalf
+handoff: the decision stays blocked in the minutes and the independent investigation continues

# Stops: an unrecoverable source, an unpermitted next step; a blocked
# decision is not one.
+stop: The requirement source cannot be recovered
+stop: The next step needs an effect the mandate does not permit
+stop: An unanswered trade-off is not an `ESCALATE`
+stop: not as an interruption or as missing authorization

# Forbidden: the retired verdict word.
-: APPROVE
# Forbidden: retired skill names.
-: brainstorming
-: writing-plans
# Forbidden: the retired review protocol this skill once ran.
-: independent review
-: dispatch a reviewer
-: at most two new independent
# Overreach: settling what only the decision owner may settle.
-: decide for the owner
-: implement the requirement during think
+mandate: Restate the requirement first
